# tmux-workspace in Rust, stage 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Python core of tmux-workspace with one Rust binary that behaves the same and
runs the hot paths in a few milliseconds. Ship it as prebuilt release archives.

**Architecture:**
- **Shape:** one crate at the repo root with a library (`src/lib.rs`, every module) and a thin binary
  (`src/main.rs`). It is a module-by-module port of the Python at commit `30b1401`, which stays the
  behavioural reference. Child processes go through one spawner that traces and times out.
  Process facts (`ps`, `lsof`) go through a `Host` trait, so tests use real tmux with fake processes.
- **Commands not yet ported:** `dash`, `ai` and `cleanup` exec the unchanged Python, which moves into
  `legacy/`.

**Tech Stack:** Rust 1.89+ (edition 2024), `serde_json` (`preserve_order`), `libc`, `rusqlite`
(`bundled`), tmux 3.3+, fzf 0.38+, bash 3.2 (`install.sh`), GitHub Actions, Docker for the
Linux matrix.

**Spec:** `docs/superpowers/specs/2026-11-05-rust-core-design.md`

## Global Constraints

- **Behavioural reference:** the Python at `30b1401`. Read it with
  `git show 30b1401:bin/tmux-workspace` (or `:integrations/agent-hook.py`, `:lib/paths.py`, …).
  Line numbers below refer to that commit.
- **Package:** `tmux-workspace` 2.0.0, edition 2024, `rust-version = "1.89"` (`File::lock`).
  One binary, `tmux-workspace`.
- **Release profile:** `opt-level = 3`, `lto = "thin"`, `codegen-units = 1`, `strip = true`,
  `panic = "unwind"`.
- **Dependencies:** exactly `serde_json = { features = ["preserve_order"] }`, `libc`,
  `rusqlite = { features = ["bundled"] }`. No dev-dependencies.
- **Floors:** tmux 3.3; macOS and Linux (glibc and musl); fzf 0.38; `install.sh` stays bash 3.2.
- **Error contract:**
  - A failing command writes `Workspace error: <message>` to stderr. When `TMUX` is set it also
    runs `display-message 'Workspace: <message>'`. Exit 1.
  - EOF at a prompt exits 0 silently.
- **Hook contract:**
  - `agent-hook` writes stdout only for `claude-status` (`Claude | <first 8 of session id>`), never
    writes stderr, and always exits 0.
  - It catches errors and panics (the panic hook prints nothing).
  - Every child process gets a 2 s timeout. Stdin over 1 MiB is ignored.
- **JSON written to files or tmux options is byte-identical to Python's `json.dumps`:** ensure_ascii,
  the Python float repr, Python's separators, insertion order (or `sort_keys`). Use `pyjson`
  (Task 2) for every such write.
- **Environment variables:** `TMUX_WORKSPACE_STATE_DIR`, `TMUX_WORKSPACE_PROJECTS`,
  `TMUX_WORKSPACE_SHELL` and `TMUX_WORKSPACE_ZOXIDE_CD` keep their meaning. New:
  `TMUX_WORKSPACE_TRACE` (Task 1), `TMUX_WORKSPACE_SHARE` (Task 3), `TMUX_WORKSPACE_DIST` and
  `TMUX_WORKSPACE_BINARY` (Task 13).
- **Call-count contract** (enforced by `tests/calls.rs`):

  | Scenario | tmux calls | ps calls |
  |---|---|---|
  | Hook, `PreToolUse` for `Bash` | 0 | 0 |
  | `pane-start`, labelled pane, `TMUX_WORKSPACE_SHELL` set | ≤ 2 | 0 |
  | `pane-start`, labelled pane, shell from the server | ≤ 2 | 0 |
  | `help` (no fzf, non-interactive) | 0 | 0 |
  | `save` with N panes | ≤ 4 + N | ≤ 2 |
- **Commit discipline:** every commit builds; `make test` stays green. Commit messages end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Spec clarifications (decided in planning; the executor treats them as spec)

1. **`rusqlite` (bundled) is a dependency.** Codex identity reads Codex's `state_*.sqlite`
   (agent-hook.py:191-203). Python used its built-in `sqlite3`; a CLI fallback would break Linux.
2. **`serde_json` uses `preserve_order`,** so re-written JSON keeps Python's key order.
3. **The hook finds `tmux` and `lsof` on `PATH`.** It falls back to `/opt/homebrew/bin/tmux` and
   `/usr/sbin/lsof`. Python hard-codes those paths (agent-hook.py:17, :156), so its hook silently
   does nothing on Linux and Intel Macs. This is a fix; it goes in the CHANGELOG.
4. **`save` makes ≤ 2 `ps` calls, not ≤ 1.** One call per table, as Python does. Merging them
   would mean re-deriving `lstart` text, which `live_app` compares byte-for-byte with the hook's
   `birth`.
5. **Release asset names carry no version:** `tmux-workspace-<target>.tar.gz`. Then
   `releases/latest/download/…` works without an API call. The version is the archive's top
   directory name and its `VERSION` file.
6. **The binary always lives at `<root>/bin/tmux-workspace`,** where `<root>` holds `tmux.conf`. In a
   checkout, `install.sh` copies the built (or downloaded) binary there; the file is gitignored.
   In a release, it is in the archive. `~/.local/bin/tmux-workspace` links to it, as today.
7. **The tmux-config tests stay in Python until stage 3.** These are the `Parse`, `Marks`,
   `TurnOverAndSeen`, `PaneZoom` and `Sound` classes of `test_agent_status_tmux.py`, plus the
   shell-script tests in `test_portability.py` (`Helpers`, `ShellIntegration`). They exercise
   `tmux.conf`, `agent-status.conf` and shell scripts, not Python code.
8. **`text::is_printable` follows Python's `str.isprintable` except for unassigned code points
   (Cn).** Rust has no Unicode category table, and those code points stay.
9. **Cosmetic differences from Python:**
   - OS error text uses Rust's `io::Error` wording.
   - Ctrl-C ends a prompt by signal rather than exit 0.
   - Labels and options read through `display-message` resolve inherited options. The code never
     sets those options globally.

## Review Focus

1. **Non-ASCII names, labels and paths** (accents, emoji, CJK) through `pyjson`, `clean_label`,
   `fields`, fzf row padding (Python pads by code point, as Rust `{:<24}` does) and `shlex_quote`.
   Expected: identical bytes to Python. Tests: Task 2 (`pyjson_matches_python_*`), Task 12
   (`save_writes_the_same_snapshot` uses a workspace named `café 😀`).
2. **The hook when tmux is gone, the socket is stale or `tmux` is not on `PATH`.** Expected: no
   output, exit 0, done within the timeout. Test: Task 4 (`hook_is_silent_when_the_server_is_gone`).
3. **tmux 3.4 output escaping in the new batched reads.** `\037` for `\x1f`, and `\$` for `$`, in
   `display-message -p`. Expected: the same values as Python's separate reads. Tests: Task 1
   (`separator_written_as_text_is_restored_for_any_format_call`), Task 6 (`pane_start_reads_label_with_dollar`).
   The tmux 3.4 container run in Task 14 exercises both.
4. **A live server where Python and Rust writers interleave** (the upgrade). Expected: snapshots
   restore both ways; the compare-and-set guards hold. Tests: Task 12, round trips in both
   directions and hook interleaving.
5. **Installer download failures:** checksum mismatch, no curl or wget, unsupported platform.
   Expected: nothing written, a clear error, exit 3. Tests: Task 13
   (`checksum_mismatch_writes_nothing`, `unsupported_platform_without_cargo_exits_3`,
   `missing_downloader_exits_3`).

**Interfaces:**
- Produces:
  - `error::Error` — `enum { Msg(String), Command { argv: Vec<String>, status: i32 }, Io(io::Error), Json(String), Eof }`.
    `Display`: `Msg` → the text. `Command` →
    ``Command '['tmux', 'kill-session', '-t', '=x']' returned non-zero exit status 1.``
    (a Python list repr: single-quoted, with `\` and `'` escaped).
  - `type Result<T>`, `fn fail<T>(msg: impl Into<String>) -> Result<T>`.
  - `process::Spawn { argv: Vec<String>, stdin: Option<String>, timeout: Option<Duration>, cwd: Option<PathBuf>, inherit_stdio: bool }`.
  - `process::Output { status: i32, stdout: String, stderr: String }`.
  - `process::spawn(&Spawn) -> Result<Output>`. It traces, and kills the child on timeout
    (`Error::Msg("timed out: <argv0>")`).
  - `process::run(argv: &[&str]) -> Result<Output>` (capture, no timeout).
  - `process::which(name: &str) -> Option<PathBuf>` (like `shutil.which`).
  - `process::exec(argv: &[String]) -> Error` (`CommandExt::exec`; returns only on failure).
  - Trace: when `TMUX_WORKSPACE_TRACE` names a file, every spawn and exec appends
    `<basename(argv0)> <args joined by ' '>\n` to it (O_APPEND).
  - `host::Host` — `trait { fn run(&self, argv: &[String]) -> Result<String>; fn parent_pid(&self) -> i32; }`,
    where `run` is checked, has a 2 s timeout, discards stderr and strips stdout at both ends.
    `host::RealHost` implements it.
  - `tmux::SEP = '\x1f'`, `tmux::Fields` (`get(&str) -> &str`, empty when missing; `set`).
  - `tmux::Tmux` with these methods:
    - `new()`: `which("tmux")` or `/opt/homebrew/bin/tmux`.
    - `socket(path)`: adds `-N -S <path>`.
    - `timeout(d)`.
    - `run(&[&str]) -> Result<String>`: check, `rstrip('\n')`, and `\037` → SEP when any arg
      contains SEP.
    - `quiet(&[&str]) -> String`: Python's `check=False`.
    - `option(name, target: Option<&str>) -> String`: `show-options -qv` with `-p -t` or `-g`.
    - `put(name, value, target) -> Result<()>`.
    - `fields(command, names, args) -> Result<Vec<Fields>>`: bin:48-58, including its
      "unsupported control characters" error.
    - `read(target: Option<&str>, names: &[&str]) -> Result<Fields>`: one `display-message -p`.
    - `chain(cmds: &[Vec<String>]) -> Result<String>`: one call joined by `;` args.
  - `cli::main() -> i32`, the dispatcher. Unknown command → `Unknown workspace command: <c>`.
    No argument → `open`.
  - `testing::ScratchTmux::new()`, `.tmux(&[&str]) -> String`, `.pane(&[&str]) -> String`,
    `.socket()`, `.expand(target, fmt)`, `.bin() -> std::process::Command`. `bin()` presets
    `TMUX=<socket>,1,0`, the state dir, `HOME=<temp>`, `TERM=xterm-256color`, and clears
    `TMUX_PANE`. Behaviour follows tests/support.py:33-60 (`-u -L <name> -f /dev/null`, session
    `alpha`, window `one`, 120x40, `exec sleep 300`). Drop kills the server.
  - `testing::TempDir::new() -> TempDir` (`.path()`, removed on Drop).

### Task 13: Packaging and install.sh

**Files:**
- Create: `scripts/package.sh`
- Modify: `install.sh`, `tests/test_install.py`, `tests/install/smoke.sh`,
  `tests/install/matrix.sh`, `Makefile` (`dist` target)

**Interfaces:**
- Produces:
  - **`scripts/package.sh TARGET [OUTDIR]`:**
    - Runs `cargo build --release --locked --target TARGET`.
    - Writes `OUTDIR/tmux-workspace-TARGET.tar.gz`. The archive has one top directory,
      `tmux-workspace-<version>/`, with the layout from spec §6 plus `VERSION`.
    - Appends to `OUTDIR/SHA256SUMS`, in `sha256sum` format.
  - **`install.sh`:**
    - **Removed:** the Python requirement and `--deps` installing Python.
    - **New flag** `--version vX.Y.Z`.
    - **Environment:**
      - `TMUX_WORKSPACE_DIST`: a base URL or a local directory holding the archives and
        `SHA256SUMS`. The default is `https://github.com/ahmmkh/tmux-workspace/releases/latest/download`,
        or `…/releases/download/<version>` with `--version`.
      - `TMUX_WORKSPACE_BINARY`: use this binary file instead of building or downloading.
      - `TMUX_WORKSPACE_HOME`: now the extract directory. The default is
        `~/.local/share/tmux-workspace`.
    - **New functions:**
      - `detect_target`: Darwin arm64 → `aarch64-apple-darwin`, Darwin x86_64 →
        `x86_64-apple-darwin`, Linux x86_64 → `x86_64-unknown-linux-musl`, Linux aarch64/arm64 →
        `aarch64-unknown-linux-musl`, anything else → empty.
      - `fetch URL DEST`: curl, else wget, else die exit 3 with
        `need curl or wget to download tmux-workspace`.
      - `verify FILE SUMS`: `sha256sum`, else `shasum -a 256`. On a mismatch, die exit 3 with
        `checksum mismatch for <file>; nothing was installed`.
      - `install_binary`:
        - Checkout: `TMUX_WORKSPACE_BINARY`, else with cargo `cargo build --release --locked`,
          else download. The result goes to `$REPO/bin/tmux-workspace`.
        - Remote: download, verify, extract into `$HOME_SHARE/<version>`, then
          `ln -sfn <version> current`. Keep only `current` and the previous version.
        - No target and no cargo: die exit 3 with
          `no prebuilt binary for <os>/<arch>; install Rust (https://rustup.rs) and rerun`.
    - **Integrations:** `--agents` and the uninstall path run
      `TMUX_WORKSPACE_SHARE="$REPO" "$REPO/bin/tmux-workspace" integrations install|uninstall`.
    - **Python:** without `python3` 3.9+, `say warn "python3 3.9+ not found: dash, ai and cleanup need it until they are ported"`.
